What is cnc

Computer numerical control coordinates machine motion through programmed instructions.

Core principle

Subtractive machining removes material. CAD describes geometry and CAM can generate toolpaths.

Practical context

Precision depends on machine behavior, material and inspection. Operation requires appropriate training.
